# COBOL Examples 
This is a collection of example and test COBOL programs I've written. I'm currently in the process of updating 
each folder with a README.md file and more comments so that the examples are easier to follow along with.

## Java Implementations

For developers interested in comparing COBOL concepts with modern Java approaches, this repository includes Java Spring Boot implementations of selected COBOL examples:

- **[java-implementations/trim-spring/](java-implementations/trim-spring/)** - Java Spring REST API equivalent of the [trim/](trim/) COBOL example

These Java implementations demonstrate how traditional COBOL functionality can be translated into modern web services while maintaining the same core logic and behavior.

All program were written using [GnuCOBOL](https://gnucobol.sourceforge.io/) in Linux.
